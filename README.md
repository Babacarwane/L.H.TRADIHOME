# Configurateur Tradi'home

Configurateur 3D interactif pour personnaliser votre maison Tradi'home.

## Démo en ligne

Le configurateur est disponible à cette adresse : 
https://babacarwane.github.io/L.H.TRADIHOME/

## Intégration dans Webflow

Pour intégrer ce configurateur dans votre site Webflow, utilisez un élément **Embed** avec ce code iframe :

```html
<div style="width: 100%; height: 100vh; min-height: 800px;">
  <iframe 
    src="https://babacarwane.github.io/L.H.TRADIHOME/" 
    style="width: 100%; height: 100%; border: none;"
    title="Configurateur Tradi'home"
    allow="fullscreen">
  </iframe>
</div>
```

## Fonctionnalités

- ✨ Visualisation 3D interactive
- 🎨 Personnalisation complète (bardage, menuiserie, toiture, etc.)
- 📊 Calcul énergétique en temps réel
- 💰 Prix dynamique
- 📱 Responsive mobile
- 📄 Export PDF
- 📅 Intégration Calendly
- 📍 Questions de qualification (terrain, timeline)

## Technologies

- Model Viewer (Google)
- jsPDF
- Calendly
- Vanilla JavaScript
